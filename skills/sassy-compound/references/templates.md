# Learning document templates

Read this before writing a learning doc.

## Bug track

```markdown
---
title: <outcome-stating title>
category: <category>
tags: [<tag>, <tag>]
created: YYYY-MM-DD
---

## Problem
What broke, and for whom.

## Root cause
The causal chain, with file:line references.

## Solution
What fixed it, with the key code.

## Prevention
The test or guard that stops it recurring.
```

## Knowledge track

```markdown
---
title: <outcome-stating title>
category: <category>
tags: [<tag>, <tag>]
created: YYYY-MM-DD
---

## Context
What the situation was.

## Guidance
The durable insight, with key examples.

## Applicability
When this applies and when it does not.
```

Keep the doc focused on the one learning. No preamble, no session narration.
